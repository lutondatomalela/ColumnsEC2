# ColumnsEC2 v0.2.0

## Desktop workspace

- Navigation organised around Data, Settings, Results and Export.
- Overview with the four project steps and the current analysis status.
- Project settings grouped into materials/analysis, reinforcement and advanced options.
- Compact decision table per physical segment; double-click opens verification details.
- Diagnostic tables remain available in a separate area.
- Excel, PDF and DXF export commands are collected in one page.
- Export is disabled when inputs or calculation settings have changed since the analysis.
- Scrollable settings and documents for smaller windows (minimum 1000 × 650).
- Keyboard shortcuts: Ctrl+O to import, F5 to calculate.
- Fixed `Prumada nan` in the Portuguese internal report.
- Calculation-worker callbacks are dispatched through the Tk main thread.

## Installation

Extract the complete Windows x64 ZIP into a new folder and run `ColumnsEC2.exe`.
Keep `_internal` next to the executable. Python is not required.

## Verification and scope

The calculation engine, numerical expressions and design strategies are unchanged.
Automated GUI checks cover import, calculation completion, navigation, decision details,
PDF generation and invalidation after parameter changes. The packaged Windows application
also runs the runtime/calculation/Tkinter startup check.

Engineering limitations from v0.1.0 remain applicable. Review effective lengths,
load combinations and verification warnings for the project. Private project files
and standards are not distributed.
