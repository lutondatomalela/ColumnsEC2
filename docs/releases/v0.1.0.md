# ColumnsEC2 v0.1.0

Portable Windows x64 distribution. No Python installation is required.

## Installation
Download ColumnsEC2-v0.1.0-Windows-x64.zip, extract the complete archive into a folder and run ColumnsEC2.exe. Keep the executable and _internal folder together.

## Changes
- Windows executable and application icon.
- Complete PDF tables without row truncation.
- Distinct summary, technical report and calculation-memory outputs.
- Light-grey PDF headers, technical labels and consistent decimal formatting.
- CAD-compatible DXF text encoding for diameter symbols and accents.

## Verification
The packaged runtime, basic calculation and Tkinter startup passed automated Windows checks. The owner tested import, calculations and Excel/PDF/DXF exports and confirmed the visual output.

## Engineering scope
Version 0.1 remains under active engineering validation. Functional testing does not establish independent validation of all structural calculations. Review load combinations, effective lengths, second-order assumptions, serviceability and detailing. Warning states require review; zero failure counts do not mean all checks are closed. Existing reference regression tests require their original fixture, which is not included.

No private project data or copyrighted standards are distributed.
