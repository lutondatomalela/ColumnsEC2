# ColumnsEC2 v0.2.1

## Excel export performance

- Replaces the chain of workbook rewrites with a single streaming save.
- Preserves all 22 worksheet categories, imported records, computed cases and segment schedules.
- Exports a captured copy of the calculated data without changing reinforcement or recalculating the design.
- Writes in a background task and reports worksheet/row progress while results remain available for consultation.
- Temporarily disables new imports, calculations and concurrent exports during the save.
- Uses a temporary file and atomic replacement; an unsuccessful save preserves an existing destination.
- Retains Portuguese/English output and the repository hyperlink.

Regression checks cover numerical fidelity, literal text, a single workbook save,
no workbook reopening, preservation of an existing file on replacement failure,
and a GUI heartbeat during asynchronous export.

Extract the complete Windows x64 ZIP into a new folder and run `ColumnsEC2.exe`.
The structural calculation engine and the engineering limitations are unchanged.
